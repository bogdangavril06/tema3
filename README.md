### Note de Implementare (HW3):

- **Accesibilitate:** S-a atins scorul perfect de 100 prin utilizarea corectă a legăturilor dintre etichete și câmpuri (`label[for]`), a structurii semantice (`fieldset`, `legend`), a atributelor `aria-describedby` pentru erori și a unui mecanism de skip link funcțional.
- **Originalitate (Bonus):** Aplicația salvează și reîncarcă dinamic proiectele adăugate prin utilizarea API-ului `localStorage`, oferind persistență datelor chiar și după reîmprospătarea paginii.
